Chocolate Sales Dashboard – Power BI

My first Power BI report: a two-page dashboard built on a sample chocolate sales dataset, tracking sales performance by country, product, and sales rep.

 Files
File	Description
my_first_power_bi_report.pbix	Power BI report file (open in Power BI Desktop)
sample-chocolate-sales-data.xlsx	Source dataset used to build the report
 About the Data

The dataset contains 4,998 sales records spanning Jan 2023 – Sep 2024, with the following fields:

Sales Person – 25 sales reps
Product – 22 chocolate products (e.g. Milk Bars, 85% Dark Bars, White Choc)
Country – USA, UK, India, Canada, Australia, New Zealand
Date – order date
Amount – order value
Boxes – number of boxes sold
Order Status – Placed, Shipped, Delivered, Cancelled
 Report Pages

Page 1 – Shipping Overview

Column chart: boxes shipped by country
Bar chart: boxes shipped by sales person
KPI cards
Product slicer

Page 2 – Revenue Overview

Line chart: revenue trend by month
Donut chart: revenue by country
Table: revenue by sales person
Bar chart: revenue by product
KPI cards
Date slicer
 Tools Used

 How to View

 Notes

This is a learning/practice project built to get hands-on with Power BI basics: data modeling, chart types, cards, slicers, and cross-filtering.
